# Bot_Binomo

Herramienta de asistencia y análisis técnico para la operativa en Binomo (Crypto IDX), diseñada para ejecutarse en entornos móviles mediante Pydroid, con sincronización en bloques de 5 minutos e integración de control a través de un bot de Telegram.

## 🚀 Características Principales

* **Análisis Técnico:** Incorpora medias móviles exponenciales (EMA de 50 y 200 periodos), Bandas de Bollinger y RSI de 14 periodos para filtros estrictos de alta asertividad.
* **Control por Telegram:** Bot interactivo con botones para el registro de resultados y monitoreo de estadísticas diarias.
* **Optimización Móvil:** Estructurado para mantener la estabilidad operativa evitando restricciones de energía en Android.

## ⚙️ Requisitos e Instalación

1. Entorno de ejecución compatible con Python (Pydroid).
2. Instalación de dependencias listadas en el archivo `requirements.txt`.
3. Configuración de credenciales de Telegram y parámetros de capital.
